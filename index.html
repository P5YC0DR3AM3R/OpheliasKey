Every dollar of a liveaboard refit — ingested, gated, attributed

Ophelia's Key (okey) turns the paper trail of a boat refit into a queryable ledger. It pulls every purchase from Gmail, Amazon Business and the bank, separates project spend from personal spend in a shared account, attributes each line item to a boat system, and reports cost, budget variance and risk — and it would rather report NULL than a plausible-looking wrong number.

Pipeline

raw capture is immutable; everything after it is derived
GmailJSON-LD orders AmazonBusiness API / CSV Plaidbank transactions ▶ raw_documentscompressed · immutable ▶ parseorders + line items ▶ classifyrules · LLM · review ▶ reconcileorders vs. bank ▶ reports

When a vendor parser improves, okey parse --reparse rebuilds every derived table from the raw store — the mailbox is never re-walked, and yesterday's bug does not become today's permanent record.

Invariants

break one and the numbers stop being trustworthy

Raw capture is separate from parsing

Every fetched email, API response and bank transaction is stored compressed and immutable. Orders and line items are derived, and rebuildable.

Nothing is guessed

Unclassifiable stays NULL. An ambiguous match stays unreconciled. An unknown price stays NULL — surfaced in a report, not filled in.

The total carries its own error bar

Undecided spend is never folded silently into boat or personal; it is reported as its own figure, so you know how far the headline number could still move.

Money is integer cents

No float ever touches a dollar figure — not in parsing, not in analysis, not in a report.

Classification

two questions · three passes

Relevance — is this purchase for the vessel at all? System — which of the 30 boat systems does it belong to?

1

Rules

Free, instant, auditable. They settle what keywords can settle with high precision, and leave everything else NULL.

2

LLM against the vessel spec

A TP-Link PoE switch is a household gadget in the abstract — against a boat running six 4K PoE cameras it is obviously camera infrastructure. The spec is prompt-cached, billed once per batch.

3

Human review

The keyboard-driven queue clears anything still ambiguous. Manual verdicts are final — neither the rules nor the LLM overwrite them.

The floating studio

the boat is also a stage

Songwriters perform aboard. The set is livestreamed over the Starlink already fitted, the audio runs through an Audient iD4 mkII, and live lyrics from Lyric Show — the caption and translation app — are composited onto the stream through its OBS overlay. The stream is the marketing: viewers watch two-language captions work and install the app.

The set is cut live by the Producer, a directing layer above the vessel agent: it tracks and frames performers across six fixed pan-tilt cameras and a handheld running Continuity Camera, colour-corrects each source so they agree, paces the cuts and draws the overlays. A stereo pair aboard carries the room underneath the close-miked performance. The systems console draws the whole chain, and the power it costs.

On competition nights the boat hosts Paradise Busker — acts rotate across the cockpit deck, the swim platform and the rear dock, and the same overlay that captions the stream captions the dock screen. One show, two audiences, each converting at its own declared rate.

okey report studio keeps the model honest: every funnel input states whether it is assumed, observed or overridden, and from the first logged show, recorded numbers replace modeled ones.

Privacy & license

a private tool, in public view

The database holds personal purchase history and never leaves the machine; the dashboard binds to 127.0.0.1 and is read-only. Data, environment and secrets are gitignored. The code is proprietary — built for the Ophelia's Key vessel project — and the taxonomy, specification models and purchase data may not be reused without written permission.
